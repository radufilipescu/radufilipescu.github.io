Souls Arena POC assets

All arena geometry, fighters, poses and visual effects are generated by src/arena.rs.
The eight PCM sound effects are original procedural synthesis. Regenerate them
with Python 3: python scripts/generate_audio.py. No external sound recordings are used.

Cinzel variable font by Natanael Gama (SIL Open Font License 1.1):
https://github.com/google/fonts/tree/main/ofl/cinzel
License: fonts/Cinzel-OFL.txt

Barlow Regular by Jeremy Tribby (SIL Open Font License 1.1):

License: fonts/Barlow-OFL.txt
